# 🔌 QA Testing API - Gestión de Kit

<p align="center">

### 🧪 Proyecto de Quality Assurance

API Testing · Pruebas funcionales · Pruebas negativas · Clases de equivalencia · Valores límite

</p>

---

## 🎯 Objetivo

Validar el correcto funcionamiento de una API REST orientada a la
gestión de kits y productos, verificando las operaciones de consulta,
creación, actualización y eliminación, así como el cumplimiento de
las reglas de negocio establecidas.

---

## 🧪 Pruebas realizadas

| Tipo de prueba | Descripción |
|---|---|
| 🔎 Pruebas funcionales | Validación del comportamiento de los endpoints |
| ❌ Pruebas negativas | Validación ante datos y solicitudes inválidas |
| 🔄 Pruebas CRUD | Validación de operaciones GET, POST, PUT y DELETE |
| 📋 Diseño de casos | Elaboración y ejecución de casos de prueba |
| 🧩 Clases de equivalencia | División de datos en grupos válidos e inválidos |
| 📐 Valores límite | Validación de condiciones límite |
| 🔗 API Testing | Validación de endpoints mediante Postman |
| ⚙️ Reglas de negocio | Verificación de las restricciones del sistema |
